# atxminis.com

Static portfolio site for ATXminis / Evan Lapka Miniature Modeling. No build step: `index.html` plus `img/`.

## Hosting
Cloudflare Pages, connected to this repo. Build command: none. Output directory: `/`.

## Contact form
The form posts to Formspree. Create a free form at formspree.io sending to the studio inbox, then replace `FORM_ID` in `index.html` with the form's ID. Until then the form tells visitors to email directly.

## Images
Web copies are resized to 1800px on the long edge (hero 2400px), JPEG quality 80. Keep originals elsewhere.
